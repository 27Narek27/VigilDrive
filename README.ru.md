### Система обнаружения сонливости водителя и экстренного оповещения близких

</div>

VigilDrive — приложение для Windows, которое использует камеру, компьютерное зрение и собственную модель машинного обучения для обнаружения сонливости водителя. Если глаза остаются закрытыми слишком долго, приложение включает громкий сигнал, а затем отправляет родственникам через Telegram фотографию, предупреждение и геолокацию автомобиля.

> **Важно.** VigilDrive — вспомогательная система, а не замена внимательности, отдыху и ответственности водителя. Она не гарантирует предотвращение аварий. Нельзя продолжать движение в сонном состоянии.

## Возможности

- мониторинг лица и глаз в реальном времени;
- классификация сонливости моделью `vigil_model_v7_best`;
- подсчёт длительности закрытия глаз;
- звуковой сигнал через 2 секунды;
- экстренное уведомление через 15 секунд;
- отправка в Telegram фотографии, текста и геолокации;
- подписка родственников по коду водителя;
- браузерный GPS и резервная IP-геолокация;
- автоматический выбор CUDA или CPU.

## Как это работает

Приложение получает кадры с камеры, определяет сонливость с помощью EfficientNet-B0 и анализирует глаза через MediaPipe Face Mesh и EAR. После 2 секунд закрытых глаз включается сигнал. Через 15 секунд текущий кадр отправляется backend-серверу, а подписчики получают фото, текстовое предупреждение, ссылку на карту или координаты и время события.

## Технологии

Python, PyTorch, torchvision, EfficientNet-B0, OpenCV, MediaPipe Face Mesh, CustomTkinter, FastAPI, Uvicorn, SQLite, Telegram Bot API, Browser Geolocation API, OpenStreetMap Nominatim и IP-геолокация.

## Запуск в Windows

Готовый executable называется **Sunlight**. Основная система — Windows 11; Windows 10 официально не подтверждена. Запустите приложение, в Telegram используйте `/register`, введите код водителя в VigilDrive, передайте его родственникам для команды `/subscribe CODE` и нажмите **START MONITORING**.

## Запуск из исходников

```powershell
git clone https://github.com/27Narek27/VigilDrive.git
cd VigilDrive
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Поместите `vigil_model_v7_best.pth` в корень проекта и запустите в отдельных терминалах:

```powershell
uvicorn Server:app --host 127.0.0.1 --port 8000
python bot.py
python main.py
```

Токен Telegram-бота храните в секретной переменной окружения или secret manager. Не добавляйте его в код или GitHub.

## Геолокация

Сначала приложение запрашивает точный GPS через временную страницу браузера. Если GPS недоступен, используется приблизительная IP-геолокация. GPS преобразуется в адрес через OpenStreetMap Nominatim; IP-данные могут определять только город или регион.

## Модель и обучение

`vigil_model_v7_best.pth` — EfficientNet-B0 с классами `Drowsy` и `Non Drowsy`. [train.py](train.py) ожидает ImageFolder-датасет `final_dataset/` с папками `Drowsy/` и `Non Drowsy/`. Обучение рассчитано на 20 эпох, validation split 15% и batch size 32.

## Ограничения

Основная система — Windows 11. Плохое освещение, очки, положение камеры и недоступный GPS могут снижать надёжность. Для Telegram-оповещений нужен интернет. Система не заменяет человеческий контроль и отдых.

## Настройка и состояние проекта

Это Windows-прототип для демонстрации мониторинга, в том числе для водителей грузовиков. Собственная обученная модель команды основана на EfficientNet-B0 с предварительно обученными весами torchvision. Это не новая архитектура нейросети; опубликованных метрик качества и дорожной валидации в репозитории нет.

После установки зависимостей скопируйте `.env.example` в `.env` командой `Copy-Item .env.example .env`, если собственного `.env` ещё нет. Запишите токен своего Telegram-бота в `TELEGRAM_BOT_TOKEN`. Оба процесса — сервер и бот — читают этот файл автоматически. Переменные окружения имеют приоритет. Не запускайте одновременно несколько polling-процессов одного бота.

Каждый терминал должен использовать виртуальное окружение. По умолчанию сервер доступен только локально на порту 8000. Для внешнего размещения потребуются отдельная настройка доступа и HTTPS; текущий API не следует открывать в интернет без защиты.

Веса модели и Sunlight не включены в текущие исходники. Получить доступную сборку и веса можно у авторов по контактам ниже; проверенной прямой ссылки на скачивание нет. Для исходников требуется Python с совместимыми колёсами PyTorch и MediaPipe; зафиксирован MediaPipe 0.10.21 с используемым API Face Mesh. Полная совместимость окружения не подтверждена автоматическими тестами.

Локальные распознавание и звук работают без интернета после установки модели. Telegram, IP-геолокация и получение адреса используют сеть. Browser Geolocation API может определять координаты по Wi-Fi и другим источникам, а не аппаратному GPS. Координаты кэшируются при начале мониторинга: это не непрерывное отслеживание движущейся машины.

Распознавание сочетает EAR и модель; пороги 2/15 секунд относятся к внутреннему таймеру. Сброс происходит после 1,2 секунды открытых глаз. Фото и координаты передаются серверу и Telegram; имя водителя, chat ID и подписки хранятся в SQLite. Код водителя передавайте только доверенным людям.
