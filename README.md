# VigilDrive

<div align="center">

### Համակարգ, որը հայտնաբերում է վարորդի քնկոտությունը և օգնում կանխել քնկոտության պատճառով վթարները

[Հայերեն](README.md) · [Русский](README.ru.md) · [English](README.en.md)

</div>

VigilDrive-ը Windows-ի համար նախատեսված վարորդի վիճակի մոնիթորինգի համակարգ է։ Այն օգտագործում է տեսախցիկը և մեքենայական ուսուցման սեփական մոդելը՝ վարորդի քնկոտության նշանները հայտնաբերելու համար։ Եթե վարորդի աչքերը երկար ժամանակ փակ են մնում, ծրագիրը ձայնային ազդանշան է տալիս և Telegram-ով ընտրված հարազատներին ուղարկում է լուսանկար, զգուշացման տեքստ և մեքենայի տեղադրությունը։

> **Կարևոր անվտանգության ծանուցում.** VigilDrive-ը օժանդակ համակարգ է և չի փոխարինում վարորդի ուշադրությանը, հանգստին կամ պատասխանատվությանը։ Այն չի երաշխավորում վթարների կանխարգելում։ Վարորդը երբեք չպետք է շարունակի վարել քնկոտ վիճակում։

## Հնարավորություններ

- դեմքի և աչքերի իրական ժամանակի հայտնաբերում,
- քնկոտության դասակարգում `vigil_model_v7_best` մոդելով,
- աչքերի փակ մնալու ժամանակի հաշվարկ,
- ձայնային ազդանշան 2 վայրկյանից հետո,
- արտակարգ ծանուցում 15 վայրկյանից հետո,
- իրավիճակի լուսանկարի, զգուշացման և տեղադրության ուղարկում Telegram-ով,
- հարազատների բաժանորդագրում վարորդի անհատական կոդով,
- GPS-ի և IP-ով մոտավոր տեղադրության պահուստային մեխանիզմ,
- CUDA-ի ավտոմատ օգտագործում, եթե հասանելի է, հակառակ դեպքում՝ CPU ռեժիմ։

## Ինչպես է աշխատում

1. Վարորդը Telegram բոտի միջոցով ստանում է անհատական կոդ և մուտքագրում այն հավելվածում։
2. Ծրագիրը տեսախցիկից ստանում է կադրեր և վերլուծում դեմքն ու աչքերը։
3. `vigil_model_v7_best` մոդելը գնահատում է քնկոտությունը, իսկ MediaPipe Face Mesh-ը հաշվարկում է աչքերի բացվածքը՝ EAR ցուցանիշով։
4. Աչքերը 2 վայրկյանից ավելի փակ լինելու դեպքում միանում է ձայնային ազդանշանը։
5. 15 վայրկյանից հետո ծրագիրը լուսանկարում է կադրը և backend-ին ուղարկում արտակարգ ծանուցում։
6. Telegram բաժանորդները ստանում են լուսանկարը, զգուշացման տեքստը, քարտեզի հղումը կամ կոորդինատները և ժամանակը։

## Տեխնոլոգիաներ

Python, PyTorch, torchvision, EfficientNet-B0, OpenCV, MediaPipe Face Mesh, CustomTkinter, FastAPI, Uvicorn, SQLite, Telegram Bot API, Browser Geolocation API, OpenStreetMap Nominatim և IP geolocation fallback։

## Օգտագործում Windows-ում

Պատրաստի executable-ը կոչվում է **Sunlight**։ Հիմնական թիրախային միջավայրը Windows 11-ն է։ Windows 10-ի համատեղելիությունը երաշխավորված չէ։

1. Sunlight-ի հասանելի հավաքածուն ստացեք հեղինակներից։
2. Telegram-ում ուղարկեք `/register` հրամանը և մուտքագրեք ձեր անունը։
3. Ստացված driver code-ը մուտքագրեք VigilDrive-ում։
4. Կոդը փոխանցեք վստահելի հարազատներին, որոնք պետք է օգտագործեն `/subscribe CODE`։
5. Սեղմեք **START MONITORING** և թույլատրեք տեսախցիկի ու տեղադրության հասանելիությունը։

## Գործարկում աղբյուրային կոդից

```powershell
git clone https://github.com/27Narek27/VigilDrive.git
cd VigilDrive
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Պահանջվում է նաև `vigil_model_v7_best.pth` ֆայլը նախագծի արմատում։ Գործարկեք առանձին terminal-ներում.

```powershell
uvicorn Server:app --host 127.0.0.1 --port 8000
python bot.py
python main.py
```

## Telegram-ի կարգավորում

Վարորդը օգտագործում է `/register`, ստանում անհատական կոդ և այն տեղադրում հավելվածում։ Հարազատը օգտագործում է `/subscribe CODE`։ Ծանուցումը ներառում է լուսանկարը, տեքստը, տեղադրությունը և ժամանակը։ Telegram bot token-ը պետք է պահվի գաղտնի միջավայրի փոփոխականում կամ secret manager-ում և երբեք չհրապարակվի GitHub-ում։

## Գեոլոկացիա

Ծրագիրը նախ browser-ի միջոցով խնդրում է բարձր ճշգրտության GPS և տվյալը փոխանցում է localhost-ին։ GPS-ի անհասանելի լինելու դեպքում օգտագործվում է IP-ով մոտավոր տեղադրություն։ GPS հասցեն լրացվում է OpenStreetMap Nominatim-ով, իսկ IP fallback-ը կարող է ցույց տալ միայն քաղաքը կամ տարածաշրջանը։

## Մոդել և ուսուցում

`vigil_model_v7_best.pth`-ը EfficientNet-B0 մոդել է՝ `Drowsy` և `Non Drowsy` դասերով։ [train.py](train.py)-ը ակնկալում է հետևյալ ImageFolder կառուցվածքը.

```text
final_dataset/
├── Drowsy/
└── Non Drowsy/
```

Ուսուցման կարգավորումները՝ 20 epoch, validation split՝ 15%, batch size՝ 32, իսկ GPU-ի դեպքում՝ CUDA mixed precision։

## Կարգավորում և նախագծի վիճակ

VigilDrive-ը Windows-ի ցուցադրական նախատիպ է՝ վարորդների, այդ թվում՝ բեռնատարների վարորդների համար։ Թիմի ուսուցանած մոդելը հիմնված է torchvision-ի նախապես ուսուցանված EfficientNet-B0-ի վրա։ Սա նոր նեյրոնային ճարտարապետություն չէ։ Պահոցում հրապարակված չեն ճշգրտության չափումներ կամ ճանապարհային փորձարկումների արդյունքներ։

Կախվածությունները տեղադրելուց հետո կատարեք `Copy-Item .env.example .env`, միայն եթե տեղական `.env` դեռ չունեք։ `TELEGRAM_BOT_TOKEN` դաշտում գրեք ձեր բոտի գաղտնի token-ը։ Սերվերն ու բոտը այն կարդում են ավտոմատ։ Միջավայրի փոփոխականներն ունեն առաջնահերթություն։ Միևնույն բոտի համար միաժամանակ գործարկեք միայն մեկ polling գործընթաց։

Յուրաքանչյուր terminal-ում ակտիվացրեք վիրտուալ միջավայրը։ Սերվերը սկզբնապես հասանելի է միայն տեղական 8000 պորտում։ Հանրային տեղակայման համար անհրաժեշտ են առանձին նույնականացում և HTTPS պաշտպանություն։

Մոդելի կշիռներն ու Sunlight-ը չեն ներառված ընթացիկ աղբյուրային կոդում։ Հասանելի հավաքածուն ու կշիռները ստանալու համար դիմեք հեղինակներին․ ստուգված ուղղակի ներբեռնման հղում չկա։ Անհրաժեշտ է Python-ի տարբերակ, որի համար հասանելի են PyTorch և MediaPipe փաթեթները։ MediaPipe 0.10.21-ն ընտրված է Face Mesh-ի օգտագործվող API-ի համար։ Ամբողջ միջավայրի համատեղելիությունը դեռ հաստատված չէ ինտեգրացիոն փորձարկմամբ։

Մոդելը տեղադրելուց հետո ճանաչումն ու ձայնն աշխատում են տեղական՝ առանց ինտերնետի։ Telegram-ը, IP տեղադրությունը և հասցեի ստացումը պահանջում են ցանց։ Browser Geolocation API-ն կարող է օգտագործել Wi-Fi կամ այլ աղբյուրներ՝ առանց իրական GPS սարքի։ Կոորդինատները պահվում են մոնիթորինգը սկսելու պահին և չեն թարմացվում անընդհատ շարժման ընթացքում։

Հայտնաբերման վրա ազդում են և՛ EAR-ը, և՛ մոդելը։ 2/15 վայրկյան շեմերը վերաբերում են ներքին ժամանակաչափին։ Աչքերը 1,2 վայրկյան բաց պահելը վերակայում է այն։ Լուսանկարն ու տեղադրությունը փոխանցվում են սերվերին և Telegram-ին։ SQLite-ում պահվում են անունները, chat ID-ները և բաժանորդագրությունները։ Վարորդի կոդը տրամադրեք միայն վստահելի մարդկանց։

## Ստուգումներ և մասնակցություն

`python -m unittest discover -s tests -v` հրամանը ստուգում է Telegram-ի պատասխանների մշակումը՝ առանց իրական հաղորդագրություններ ուղարկելու։ Տեսախցիկը, ձայնն ու ծանուցումները փորձարկեք աշխատասեղանի մոտ կամ կանգնած մեքենայում։ Առաջարկները ներկայացրեք GitHub Issues-ում, իսկ pull request-ում նշեք ստուգման քայլերը։ Այս թեստերը չեն հաստատում ճանապարհային անվտանգությունը։
